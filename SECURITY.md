# Security Policy

## Supported Versions

Please note that the version below contains some bugs; we will explain how to use it.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.0  | This version has serious issues; as it is the initial release, we are no longer maintaining it. |


## Usage Recommendations

We recommend using a newer client version; otherwise, your computer may be unable to run the application.

We advise against modifying the source code yourself; however, if you have an idea for a new feature, we recommend contacting us at `mail@shit.pub` to collaborate on its development. We accept no liability for any damage to your device resulting from code modifications you make. Thank you for your understanding and support.
