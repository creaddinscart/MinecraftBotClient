# Quick Start Guide

## Fastest Way to Get Started

### 1. Download the Latest Release
Go to: https://github.com/creaddinscart/MinecraftBotClient/releases

Download `MinecraftBotClient.exe` from the latest release

### 2. Run the Executable
Double-click `MinecraftBotClient.exe` and follow the on-screen prompts

### 3. Configure
- Enter your username (or press Enter for random)
- Enter server address (default: localhost:25565)
- Select Minecraft version (default: 1.8.9)
- Set spam interval in seconds (default: 5)

### 4. Start Playing
Connect to your Minecraft server and chat!

## Quick Command Reference

```
help              - Show all commands
/spam hello       - Spam "hello" 10 times
/stopspam         - Stop spam
/settings         - View current settings
exit              - Disconnect and close
```
